# 词序 · 真题词汇

从 75 页真题词汇照片整理的考研英语一学习网站，按 2010—2026 年分类，部署到 GitHub Pages。

## 功能

- 按年份浏览、英文及中文搜索、掌握状态筛选。
- 单词卡、看义拼写、听音拼写；支持浏览器英式/美式语音及语速调整。
- 间隔复习：不认识 10 分钟后重现；记住后依次延长到 1、3、7 天及更长间隔。
- 生词收藏、错词回顾、每日目标、学习天数、连续学习与近两周统计。
- 本机自动保存，退出后续学，JSON 备份导出与导入。
- 每个词条保留年份、题型、页码及原图。相同年份的重复词合并，不同年份分别记录进度。
- 响应式布局及键盘快捷键。

## 使用

打开网站直接开始学习。学习数据只保存在当前浏览器，不会上传到 GitHub；换设备或清理浏览器前请在“学习设置”中导出备份，再在新设备导入。

发音使用系统或浏览器提供的英语语音。可用口音和离线朗读能力取决于设备；页面没有外部付费 API。

## 本地运行

安装 Node.js 后在此目录执行 `npm start`，打开 http://127.0.0.1:4173 。无需安装依赖。使用 `npm test` 运行词库和复习、备份逻辑检查。

## 部署

GitHub 仓库 Settings → Pages → Deploy from a branch → `main` / 根目录。全站使用相对路径，可直接发布在项目 Pages 地址下。

## 数据

`data/vocabulary.json` 保存词库，`data/pages/` 保存经压缩的来源图片，`data/quality-report.json` 保存识别及校对说明。已按年份、拼写、词性、中文释义和重复词检查全库，并对识别异常的词条逐一核对原图；目前没有待核对标签。词库来自用户提供的学习资料，如果发现遗漏或错误，仍可按词条所附页码对照原图。

进度键为 `cixu.progress.v1`。词条 ID 在校对时保持稳定，少数被合并的重复词也会迁移旧进度和收藏，因此拼写与释义修订不会清除已有学习记录。
