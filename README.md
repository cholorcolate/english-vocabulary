# 词序 · 考研英语词汇

按年份学习考研英语词汇的轻量网站，打开即可使用：[在线背词](https://cholorcolate.github.io/english-vocabulary/)。支持 2010—2026 年词库，无需注册账号。

## 功能

- 按年份浏览词条，搜索英文或中文，并按学习状态筛选。
- 单词卡、看英文选中文（三选一）、看义拼写；支持发音、键盘快捷键与手机使用。
- 间隔复习：忘记的词会较快重现，记住后逐步延长复习间隔。
- 收藏生词、回顾错词、设置每日目标，查看连续学习和练习统计。
- 学满 100 个不同词条时显示一次可关闭的仓库 Star 提醒。

## 学习进度

进度自动保存在当前浏览器。换设备、换浏览器或清理网站数据前，请在“学习设置”中导出 JSON 备份，再到新设备导入。静态网站不提供账号云同步。词条校对和重复词合并会尽量保留原有进度与收藏。

## 本地运行

安装 Node.js 后，在仓库目录运行 `npm start`，访问 `http://127.0.0.1:4173`。运行 `npm test` 可检查学习逻辑与词库结构；无需安装第三方依赖。

## 数据与部署

公开词库保存在 `data/vocabulary.json`，网站可通过 GitHub Pages 从 `main` 分支根目录发布。
